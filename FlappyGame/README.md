# 🛵 Delivery Loco

A small Flappy Bird-inspired game built with C# and WPF — except instead of a bird, you're a Brazilian delivery rider trying to survive the streets and dodge speed cameras. 🇧🇷

## 🎮 Demo

![Delivery Loco Gameplay](FlappyGame/delivery-loco.gif)

[▶ Watch the full MP4 demo](FlappyGame/delivery-loco.mp4)

## 🕹️ Controls

- `SPACE` — Fly / move up
- Release `SPACE` — Fall
- `R` — Restart after Game Over

## 🧠 What I Practiced

This project was built as a hands-on way to practice C# and WPF concepts, including:

- WPF and XAML UI development
- C# event handling
- Keyboard input
- `DispatcherTimer` game loop
- Movement and gravity
- Collision detection with `Rect`
- Score tracking
- Image assets and hitboxes
- Background audio with `MediaPlayer`
- Game state and restart logic

## 🛠️ Tech Stack

- C#
- .NET
- WPF
- XAML
- Visual Studio 2022

## 🇧🇷 Custom Theme

I customized the original Flappy Bird concept into a Brazilian delivery-rider theme featuring:

- 🛵 Pixel-art delivery rider
- 📸 Brazilian-style speed cameras
- 🏙️ Pixel-art city background
- 🎵 Background music
- 🎯 Custom collision hitboxes

## 📚 Learning Project

This project was created while following and adapting a WPF Flappy Bird tutorial from Moo ICT.

I customized the visuals, gameplay elements, collision behavior, audio, and overall theme while using the project to strengthen my understanding of C# and WPF.
